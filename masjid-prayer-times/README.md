Display prayer times from Masjidal.com and calculate Nisab values using simple widgets.

== Description ==

This plugin provides WordPress widgets to enhance your Islamic website:

1.  **Masjid Prayer Times Widget**: Displays daily prayer (Salah) and congregation (Iqamah) times for a specific Masjid using the Masjidal.com API. You can configure the Masjid ID in the widget settings.
    The displayed information includes:
    *   Gregorian and Hijri dates.
    *   Adhan (Salah) times for Fajr, Sunrise, Zuhr, Asr, Maghrib, and Isha.
    *   Iqamah times for Fajr, Zuhr, Asr, Maghrib, and Isha.
    *   Jummah prayer times, if available.

2.  **Nisab Calculator Widget**: Calculates Mahr Fatimi, Minimum Mahr, and Zakaah Nisab values.
    *   It uses live silver prices fetched from Lear Capital (`www.learcapital.com/charts/generated/silver_daily.json`).
    *   The widget displays an "Updated" date indicating when the silver price data was last generated by the source.

== Installation ==

1.  Upload the `masjid-prayer-times` folder to the `/wp-content/plugins/` directory.
2.  Activate the plugin through the 'Plugins' menu in WordPress.
3.  Navigate to Appearance > Widgets.
4.  **For Prayer Times:** Find the "Masjid Prayer Times" widget and drag it to your desired sidebar or widget area.
5.  Enter the `Masjid ID` in the prayer times widget settings. You can find this ID from Masjidal.com. For example, `1QL0MDAZ`.
6.  Save the prayer times widget settings.
7.  **For Nisab Calculator:** Find the "Nisab Calculator" widget and drag it to your desired sidebar or widget area. It has no configurable options other than the title.

== Frequently Asked Questions ==

*   **Where do I find the Masjid ID for the Prayer Times widget?**
    You need to obtain the Masjid ID from Masjidal.com for the specific Masjid whose prayer times you want to display.

*   **What if the prayer times are not showing?**
    Please ensure you have entered a correct Masjid ID in the widget settings and that your website can connect to external APIs. Check for any error messages displayed by the widget.

*   **Where does the silver price for the Nisab Calculator come from?**
    The Nisab Calculator uses live silver prices fetched from `www.learcapital.com/charts/generated/silver_daily.json`. The "Updated" date shown in the widget reflects when this data was last generated by the source.
