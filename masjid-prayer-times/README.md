Display prayer times from Masjidal.com using a simple widget.

== Description ==

This plugin provides a WordPress widget to display daily prayer (Salah) and congregation (Iqamah) times for a specific Masjid using the Masjidal.com API. You can configure the Masjid ID in the widget settings.

The displayed information includes:
*   Gregorian and Hijri dates.
*   Adhan (Salah) times for Fajr, Sunrise, Zuhr, Asr, Maghrib, and Isha.
*   Iqamah times for Fajr, Zuhr, Asr, Maghrib, and Isha.
*   Jummah prayer times, if available.

== Installation ==

1.  Upload the `masjid-prayer-times` folder to the `/wp-content/plugins/` directory.
2.  Activate the plugin through the 'Plugins' menu in WordPress.
3.  Navigate to Appearance > Widgets.
4.  Find the "Masjid Prayer Times" widget and drag it to your desired sidebar or widget area.
5.  Enter the `Masjid ID` in the widget settings. You can find this ID from Masjidal.com. For example, `1QL0MDAZ`.
6.  Save the widget settings.

== Frequently Asked Questions ==

*   **Where do I find the Masjid ID?**
    You need to obtain the Masjid ID from Masjidal.com for the specific Masjid whose prayer times you want to display.

*   **What if the prayer times are not showing?**
    Please ensure you have entered a correct Masjid ID in the widget settings and that your website can connect to external APIs. Check for any error messages displayed by the widget.
