Calculates and displays Mahr Fatimi, Minimum Mahr, and Zakaah Nisab based on live silver prices.

== Description ==

The Masjid Nisab Widget provides a simple way to display important Islamic financial thresholds directly on your WordPress site. It automatically fetches the latest silver prices from Lear Capital (www.learcapital.com/charts/generated/silver_daily.json) and calculates:

*   **Mahr Fatimi:** Based on a multiplier of 47.249 times the silver price.
*   **Minimum Mahr:** Based on a multiplier of 0.984 times the silver price.
*   **Zakaah Nisab (for Silver):** Based on a multiplier of 19.688 times the silver price.

The widget also displays the date when the silver price data was last updated by the source.

== Installation ==

1.  Upload the `masjid-nisab-widget` folder to the `/wp-content/plugins/` directory.
2.  Activate the plugin through the 'Plugins' menu in WordPress.
3.  Navigate to Appearance > Widgets.
4.  Find the "Nisab Calculator" widget and drag it to your desired sidebar or widget area.
5.  You can optionally set a custom title for the widget. Otherwise, it defaults to "Nisab Calculator".
6.  Save the widget settings.

== Frequently Asked Questions ==

*   **Where does the silver price for the Nisab Calculator come from?**
    The Nisab Calculator uses live silver prices fetched from `www.learcapital.com/charts/generated/silver_daily.json`. The "Updated" date shown in the widget reflects when this data was last generated by the source.

*   **Are the multipliers configurable?**
    No, the multipliers (47.249 for Mahr Fatimi, 0.984 for Minimum Mahr, 19.688 for Zakaah Nisab) are currently fixed as per the common understanding derived from the initial example.

*   **What if the silver prices are not showing?**
    Please ensure your website can connect to external APIs (specifically `www.learcapital.com`). Check for any error messages displayed by the widget.
